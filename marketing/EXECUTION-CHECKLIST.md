## Non-social-media marketing — execute in this order

### 1. Email capture (30 min)
- [ ] Open `marketing/email/setup-guide.html`
- [ ] Create Google Form (email field only)
- [ ] Link it to Google Sheets
- [ ] Create 3-Day Sample PDF / Google Doc
- [ ] Upload to Drive, set to public
- [ ] Add first email body: `marketing/email/sample-email.html`
- [ ] Add form action to landing page `<form>` tag
- [ ] Send Email 1 immediately to yourself as test

### 2. SEO (10 min)
- [ ] Open `marketing/seo/seo-assets.md`
- [ ] Confirm meta title + description in `index.html`
- [ ] Add Open Graph + Twitter Card tags
- [ ] Add FAQ section to landing page
- [ ] Add "Who this is NOT for" section
- [ ] Submit URL to Google Search Console after custom domain

### 3. Forum / community (20 min)
- [ ] Open `marketing/forum/forum-posts.md`
- [ ] Post in r/bodyweightfitness (value-first, not salesy)
- [ ] Post in r/getdisciplined
- [ ] Post in 1 Facebook home workout group
- [ ] Answer 1 Quora question with the template

### 4. Outreach (15 min)
- [ ] Open `marketing/outreach/outreach-scripts.md`
- [ ] Find 5 people complaining about “no time to workout”
- [ ] Send value-first comment + DM only if they engage
- [ ] Never follow up more than twice

### 5. Social media scheduling (15 min)
- [ ] Open `marketing/fb/ready-schedule-2026-06-22.md`
- [ ] Go to https://business.facebook.com
- [ ] Select your Page
- [ ] Schedule all 21 posts (Mon–Sun, 8/12/18)
- [ ] Verify queue preview
