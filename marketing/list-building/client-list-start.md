# No-Gym 30 — Client List Start Engine (No Email List Required)

Goal: Move from 0 emails to 100+ real opt-ins without spending money.

## Core Strategy
1. **Earned traffic → Form capture** (what is already live: https://nogym30.netlify.app)
2. **Earned traffic → Direct outreach → Form capture** (cold but targeted)
3. **Distributed content → Signature repetition → Recall → Form capture**
4. **Google Profile + GBP → Free discovery → Form capture**

---

## Channel 1: Community Posts (Do This Today)

### Reddit
- Post to:
  - r/bodyweightfitness
  - r/Fitness
  - r/getdisciplined
  - r/selfimprovement
- Rule: Lead with value, no links
- Template: `marketing/forum/forum-posts.md`

### Facebook
- Post in groups:
  - Home workout groups
  - Parent fitness groups
  - Entrepreneur health hacks groups
- Use: `marketing/fb/ready-schedule-2026-06-22.md`

### Quora
- Answer: *“Best 30-day workout plan for beginners to do at home without equipment?”*
- Add personal voice, then end with: “I built a printable one if helpful.”

---

## Channel 2: Direct Outreach (DM 10/day)

### Target Profiles
- Instagram: #homeworkout #parentfitness
- X/Twitter: people saying “no time for gym”
- Reddit: recent posters saying they don’t know where to start

### Script
> Hey, saw your post about not having time to work out. I built a plan with 10–25 min bodyweight days and no equipment, if useful: https://nogym30.netlify.app/

## Channel 3: Google Business Profile (Free Exposure)

Steps:
1. Claim listing at https://business.google.com
2. Name: “No-Gym 30”
3. Category: Health consultant / Fitness
4. Description: `marketing/bios.md` medium text
5. Post weekly update from `marketing/fb/ready-schedule-2026-06-22.md`
6. Link URL: https://nogym30.netlify.app

---

## Channel 4: Content Repurposing Loop

Reuse existing marketing assets:
- `marketing/social-captions.md` → TikTok / Reels / Shorts hooks
- `marketing/ad-copy.md` → Gumroad / Reddit posts
- `marketing/seo/seo-assets.md` → Blog posts (Medium, dev.to)

Post slightly customized versions everywhere. Same underlying story.

---

## Channel 5: Referral / Share Mechanics

Add one-line to Google Form confirmation:
> “Forward this to one friend who says they don’t have time to workout.”

Low friction. Works.

---

## Daily Execution Cadence
- 5 Facebook/Reddit comments
- 3 DMs
- 1 Quora answer
- 1 TikTok/Reel/Short using a hook from `marketing/social-captions.md`

Repeat for 2 weeks. That puts ~100+ people in front of the form without spending money.
